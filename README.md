# VexoTTS 🎤

A lightweight text-to-speech virtual microphone application for Linux.

## Features
- Python desktop interface using Tkinter
- Virtual audio routing using PulseAudio-compatible tools
- Virtual microphone source for compatible applications

## Requirements
- Linux
- Python 3
- Tkinter
- PipeWire or PulseAudio with pactl

## Run

    python3 main.py
